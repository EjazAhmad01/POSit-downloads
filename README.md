# POSit — desktop downloads

Installers for the POSit desktop till. This repository holds **no source code**:
it exists so that the download button in POSit Web has somewhere public to point
at, which a private repository cannot provide — GitHub requires authentication
to fetch a release asset from one, so every visitor got a 404.

Get the app from the **[latest release](../../releases/latest)**, or let the Help
screen in POSit Web pick the right file for your machine.

| System | File |
| --- | --- |
| Windows 10/11 (64-bit) | `POSit-windows-x64-setup.exe` |
| macOS, Apple Silicon | `POSit-macos-apple-silicon.dmg` |
| macOS, Intel | `POSit-macos-intel.dmg` |
| Linux (64-bit) | `POSit-linux-x86_64.AppImage` |

The installers are built from the POSit source repository by its own release
workflow, on each platform's own runner, and copied here unchanged.

POSit is a product of Xelorasoft.
